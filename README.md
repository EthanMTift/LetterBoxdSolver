# LetterBoxdSolver

This program takes an image of the NYT Games **LetterBoxed** board and outputs the *most common* answers, using the wordfreq library. 

It is important that the image you select is cropped to include *only* the board and that there are **NO** connecting lines between letters (this can be accomplished by refreshing the page if you have already tried to solve the game yourself)

Any text that is in the image that is not the 12 letters of interest will break the OCR, so be warned.
